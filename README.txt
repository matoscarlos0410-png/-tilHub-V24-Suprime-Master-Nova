1. ¿QUÉ ES ÚTILHUB?
============================================================

ÚtilHub es una plataforma web que reúne diferentes
herramientas prácticas en un solo lugar.

Su objetivo es facilitar tareas cotidianas, cálculos,
conversiones, organización, productividad y otras
funciones útiles.

ÚtilHub V24 incorpora NOVA FLOW como sistema visual
global de animación.


2. ARCHIVOS DEL PROYECTO
============================================================

index.html
    Estructura principal de la página.

style.css
    Diseño, colores, tarjetas, botones, ventanas,
    modo oscuro, modo claro y estilos responsivos.

script.js
    Funciones de ÚtilHub, herramientas, almacenamiento,
    NOVA FLOW, búsqueda, favoritos y productividad.

manifest.webmanifest
    Configuración para instalar ÚtilHub como aplicación web.

sw.js
    Service Worker para funcionamiento PWA y caché.

README.txt
    Información y documentación del proyecto.


3. NOVA FLOW V24
============================================================

NOVA FLOW es el sistema de animación visual de ÚtilHub.

V24 incluye:

- 120 animaciones diferentes.
- Animaciones con comportamientos propios.
- Fondo animado global.
- Animación visible durante todo el desplazamiento.
- Efectos de partículas.
- Ondas.
- Estrellas.
- Vórtices.
- Aurora.
- Redes.
- Campos de energía.
- Geometría.
- Efectos espaciales.
- Efectos digitales.
- Sistemas de movimiento independientes.

IMPORTANTE:

Las 120 animaciones no están diseñadas únicamente para
cambiar colores o velocidad.

Cada modo utiliza una lógica visual diferente.


4. MODOS DE RENDIMIENTO
============================================================

ÚtilHub V24 incluye diferentes niveles de rendimiento:

AUTO
    Ajusta automáticamente la cantidad de efectos.

HIGH
    Mayor cantidad de partículas y efectos.

BALANCED
    Equilibrio entre calidad visual y rendimiento.

PERFORMANCE
    Reduce efectos para mejorar la velocidad.

LOW / AHORRO
    Utiliza una cantidad reducida de efectos.


5. CONTROLES DE NOVA FLOW
============================================================

El usuario puede:

- Cambiar de animación.

- Activar o desactivar efectos.
- Activar o desactivar el movimiento.
- Activar o desactivar el parallax.
- Cambiar el rendimiento.
- Usar diferentes modos de NOVA FLOW.

7. DICCIONARIO
============================================================

El diccionario utiliza una consulta externa cuando existe
conexión a Internet.

También utiliza almacenamiento local para mejorar la
velocidad de consultas repetidas.

Puede mostrar:

- Ejemplos.

8. COMIDA Y COMPRAS
============================================================

ÚtilHub NO realiza pedidos automáticamente.

El usuario decide qué comprar o pedir.

Las herramientas pueden ayudar a acceder a búsquedas
o servicios externos, pero el usuario realiza directamente
la compra o el pedido.

19. INSTALACIÓN EN GITHUB
============================================================

Para publicar ÚtilHub:

1. Crear un repositorio en GitHub.

2. Subir todos los archivos:

   index.html
   style.css
   script.js
   manifest.webmanifest
   sw.js
   README.txt

3. Activar GitHub Pages.

4. Seleccionar la rama principal.

5. Seleccionar la carpeta raíz.

6. Guardar la configuración.

7. Abrir la dirección proporcionada por GitHub Pages.


20. INSTALACIÓN COMO APLICACIÓN
============================================================

Después de publicar el sitio correctamente:

1. Abrir ÚtilHub desde un navegador compatible.

2. Buscar la opción de instalar la aplicación.

3. Seleccionar instalar.

4. ÚtilHub aparecerá como una aplicación web
   cuando el navegador y el dispositivo sean compatibles.


21. ICONO
============================================================

El proyecto utiliza un icono integrado directamente
en el código HTML mediante SVG.

No es necesario utilizar un archivo:

icon.png
icon.jpg
icon.svg

para mostrar el icono principal dentro de la página.

NOTA:

Los navegadores pueden tener requisitos específicos para
los iconos de aplicaciones PWA instalables.


22. SERVICE WORKER
============================================================

El archivo sw.js permite:

- Guardar archivos principales.
- Cargar archivos desde caché.
- Intentar actualizar recursos.
- Recuperar index.html cuando no existe conexión.
- Eliminar cachés antiguas.
- Preparar la aplicación para funcionamiento PWA.


23. ACTUALIZAR ÚTILHUB
============================================================

Cuando se publique una nueva versión:

1. Modificar los archivos necesarios.

2. Cambiar el nombre de CACHE_NAME en sw.js.

3. Subir los archivos actualizados.

4. Esperar a que GitHub Pages publique los cambios.

5. Recargar ÚtilHub.

El nuevo Service Worker podrá reemplazar la caché anterior.


24. SEGURIDAD
============================================================

ÚtilHub evita ejecutar código introducido directamente
por el usuario mediante eval() o Function() para realizar
cálculos.

Las herramientas deben validar los datos antes de procesarlos.

Las APIs externas pueden depender de la conexión a Internet.


25. PRIVACIDAD
============================================================

Los datos guardados mediante localStorage permanecen
normalmente en el navegador del usuario.

ÚtilHub no necesita una cuenta para utilizar sus
herramientas básicas.


26. COMPATIBILIDAD
============================================================

con:
